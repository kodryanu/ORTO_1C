# Закрытие заказов покупателей (УНФ 3.0)

Файл `ЗакрытиеЗаказовПокупателей_Форма.bsl` — полный модуль управляемой формы внешней обработки.
Форма строится программно, поэтому вручную в конфигураторе ничего, кроме создания пустой формы, делать не нужно.

## Как создать обработку
1. Откройте 1С:Предприятие в режиме **Конфигуратор** (любая база, можно УНФ). Файл → Новый… → Внешняя обработка.
2. В окне свойств задайте Имя `ЗакрытиеЗаказовПокупателей`, синоним «Закрытие заказов покупателей».
3. В дереве объекта: Формы → Добавить. Тип формы — управляемая форма, нажмите «Готово» (ничего не добавляя).
4. Откройте форму, вкладка «Модуль» (внизу окна формы). Удалите весь текст, вставьте содержимое `ЗакрытиеЗаказовПокупателей_Форма.bsl`.
5. Файл → Сохранить как… → `ЗакрытиеЗаказовПокупателей.epf`.
6. В УНФ: Администрирование → Печатные формы, отчеты и обработки → Дополнительные отчеты и обработки (или Файл → Открыть для внешних обработок) — откройте `.epf`.
